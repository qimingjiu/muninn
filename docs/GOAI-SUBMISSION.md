## 一、项目简介（500 字内 · 可直接复制到报名系统）

**雾尼 Muninn** 是一个通用叙事记忆引擎，首发验证场景为 **AI+教育 · 长程学情陪伴 Agent**。

现有教育 AI 能「推题」，但记不住学生三个月来卡在哪里、为什么卡、现在通了没有。雾尼提出三层叙事记忆引擎——碎片层记录带 VAD 情感坐标的事件；线索层以「未闭合的状态」为单位追踪学习卡点（草蛇灰线）；认识层以改写式活文档持续更新对学生的理解，并配套证据锚定、反证搜索、盲推导审计等全套防漂移机制。系统输出不是 top-k 卡片，而是「叙事上下文包」：相关碎片 + 线索位置 + 当前认识状态。

在长程学情陪伴场景中，雾尼完成「日常交互 → 意图理解 → 记忆编织 → 陪伴响应 + 周期学情报告 → 学生确认/否决 → 修正」的完整闭环。Demo 以「微积分第三章长期卡点」为核心叙事，演示历史压缩、学情认识生成、人为反例置信下调、伏笔回收等关键能力。

本项目不替代教师教学判断或学校评价，强调用户权利三轴：全透明可见、诠释层最终解释权、contested 删除机制。引擎本身通用，可向情感陪伴、医疗陪护、客户关系等长程 Agent 场景迁移。

## 三、评审维度应答（对照官网 Review Focus）

### 1. 行业场景价值（Industry scenario value）

**赛道要求**：属于 AI+Education 五大方向之一；解决真实用户、真实工作流中的痛点；不鼓励通用聊天机器人。

**本方案**：
- 选择 **AI+Education · 学习陪伴 / 学习诊断**，而非泛聊天
- 目标用户：长期自学者与备考学生（学习周期以月计、状态起伏大、最需要「被记得」的群体）
- 真实痛点：现有教育 Agent 能推题，但不记得学生三个月来卡在哪里、为什么卡、现在通了没有
- 与「泛聊天陪伴工具」的切割：每次交互携带「叙事上下文包」，每句判断可展开证据链

### 2. Agent 能力与闭环任务执行（Agent capabilities and closed-loop task execution）

**赛道要求**：任务理解、工作流编排、工具调用、知识增强、多轮交互、结果交付。

**本方案**：
- **任务理解**：意图识别区分新事实 / 旧线索新证据 / 情绪事件
- **工作流编排**：三层架构流水线（碎片 → 线索 → 认识）
- **知识增强**：合成句双层结构（HyDE）、反证搜索、叙事上下文包
- **多轮交互**：90 天历史压缩，跨会话连续性
- **结果交付**：即时陪伴响应 + 周期学情报告（论断 + 证据链 + 置信分 + 版本史）

**闭环**：学生表达卡点 → 识别为历史线索推进 → 更新学情认识 → 给出带证据反馈 → 学生确认或否决 → 修正。

### 3. 产品体验与 Demo 完成度（Product experience and demo completeness）

**赛道要求**：可运行 demo、视频演示或等效可验证材料。

**本方案**：
- 前端 Demo 已完成（Vite + React + Tailwind）
- 十分钟脚本覆盖 6 个关键节点：开场对比 / 历史压缩 / 学情认识 / 人为反例 / 伏笔回收 / 收尾
- 双轨判定：实时 LLM（moonshot-v1-8k）+ 预计算脚本兜底，现场稳定
- 可切换「总览 / 线索层 / 认识层 / 碎片层 / 评测体系 / 用户权利 / 现场演示」七个视图

### 4. 技术实现深度与工程可复现性（Technical implementation depth and engineering reproducibility）

**赛道要求**：解释模型、Agent 架构、工具接口、知识库、数据处理、部署方式。

**本方案**：
- **模型**：商业 LLM API（默认 Moonshot）可插拔；所有调用点可替换为开源模型
- **Agent 架构**：三层叙事记忆引擎（碎片/线索/认识）
- **知识库**：事件桶 + 合成句双层 + 六态状态机
- **数据处理**：VAD 情感坐标 + 情绪调制衰减
- **部署**：纯前端静态构建；`npm install && npm run build` 即可复现
- **可复现性**：README 含完整运行步骤；仓库含模拟数据和工程说明

### 5. 安全、合规与开放复用价值（Safety, compliance, and open reuse value）

**赛道要求**：数据授权、隐私保护、风险提示、行业边界；鼓励开放可复用组件。

**本方案**：
- 数据声明：模拟数据 + 公开数据集 + 本人授权数据
- 隐私：用户权利三轴（可见度 / 可编辑度 / contested）
- 安全：心理论断权限墙、危机协议
- 行业边界：不替代教师 / 学校评价
- 开放复用：引擎核心开源计划；评测基准「衔枝 Twig」独立开源

## 五、AI+Education 细分方向定位

官网给出 AI+Education 的五个关键词：

1. **Personalized learning** → 雾尼：长程理解驱动的个性化
2. **Homework support** → 可扩展：记录错题背后的前置知识断层
3. **Learning diagnosis** → 核心：学情报告（论断 + 证据链 + 置信分）
4. **Teacher lesson preparation** → 可扩展：学情数据辅助教师备课
5. **Learning companionship** → 首发：长程学情陪伴 Agent

本项目以 **Learning companionship + Learning diagnosis** 为双核心，其余方向为可扩展路径。
