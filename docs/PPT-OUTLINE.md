## 第 2 页 · 问题：教育 AI 的「碎片化原罪」

- 现状：教育 AI 能推题、能答疑、能生成标准答案
- 痛点：它记不住学生三个月来卡在哪里、为什么卡、现在通了没有
- 赛道警示：不鼓励泛聊天机器人、单点问答工具、简单内容生成器
- 我们的切入：**长程理解**是因材施教的前提

---

## 第 3 页 · 洞察：记忆的本质是编织，不是存储

- 人类记忆不是「存储 → 检索」
- 是「碎片 → 线索 → 认识」的持续编织
- 关键能力：
  - 跨时间连接（伏笔回收）
  - 冲突修正（矛盾响应）
  - 持续演化（改写式认识）

---

## 第 4 页 · 方案：三层叙事记忆引擎

- **碎片层**：VAD 情感坐标 + 情绪调制衰减
- **线索层**：草蛇灰线系统 —— 登记的是「未闭合的状态」，不是那句话
  - ACTIVE / DORMANT / SILENT 三池
  - 六态状态机：unresolved / resolved / dissolved / abandoned / superseded / merged
  - merge / split / lineage
- **认识层**：改写式活文档 + 证据锚定 + 反证搜索 + 盲推导审计
- 输出：**叙事上下文包**（相关碎片 + 线索位置 + 当前认识状态）

---

## 第 5 页 · 场景：长程学情陪伴 Agent

- 目标用户：长期自学者 / 备考学生
- 核心叙事：微积分第三章长期卡点 → 前置知识断层 → 暑期集训 → 限制解除
- 一句话：现有教育 AI 解决「答对这道题」，我们解决「学生在时间中变化时，AI 如何修正自己对他的理解」

---

## 第 6 页 · 任务闭环

1. 日常交互（对话 / 打卡 / 提问 / 情绪表达）
2. 意图理解（新事实 vs 旧线索新证据）
3. 记忆编织（碎片 → 线索 → 认识）
4. 结果交付（陪伴响应 + 周期学情报告）
5. 验证与反馈（过程评测 + 学生否决权）
6. 安全边界（权限墙 + 危机协议）

## 第 8 页 · 技术深度

- 六态状态机 + 三池管理
- HyDE 合成句双层结构：登记「回收长相」而非原句
- 反证搜索：HyDE 反用 + 强制 adjudication
- 盲推导审计：系统排程触发，二分定位漂移
- 用户权利三轴：可见度 / 可编辑度 / contested
- 自我实现预言断路器：belief/policy 解耦 / endogenous 标记 / 对照窗口 / 语言去定性化

---

## 第 9 页 · 评测体系：过程评测，不是结果评测

- Evidence Coverage：论断是否带着完整证据结构存活
- Contradiction Responsiveness：新冲突出现时是否降低置信、修改认识
- Memory Repair Test：旧限制解除时是否关闭线索、更新认识模型
- 事实底盘：LoCoMo 基线目标 ≥ 90%

---

## 第 10 页 · 安全、合规与用户权利

- 心理论断权限墙：只记事实，不生成准诊断推断
- 危机协议：模式切换而非冷冰冰拒绝
- 用户权利三轴：
  - 可见度：默认全透明
  - 可编辑度：事实层不可改，诠释层用户最终解释权
  - contested：删除后降级，再提须是邀请
- 数据声明：模拟数据 + 公开数据集 + 本人授权数据
